# Agent Contracts

## Lead Agent
**Input**:
- `user_objective`: string
- `constraints`: list of strings
- `current_knowledge`: list of structured claims (optional)
- `verification_results`: list of verifications (optional)

**Output (Decision)**:
- `status`: "INSUFFICIENT" | "SUFFICIENT"
- `knowledge_gaps`: list of strings (if INSUFFICIENT)
- `research_missions`: list of `ResearchMission` (if INSUFFICIENT)
- `final_verdict`: `Verdict` (if SUFFICIENT)

## Research Agents (Landscape, Feasibility, Opportunity)
**Input**:
- `mission_brief`: string (dynamically generated by Lead Agent)
- `constraints`: list of strings

**Output**:
- `findings`: list of `Claim`
- `sources`: list of strings

## Skeptic Agent
**Input**:
- `claims`: list of `Claim`
- `context`: string (investigation objective)

**Output**:
- `challenges`: list of `Challenge` (targeting specific `claim_id`s)

## Verifier Agent
**Input**:
- `claims_to_verify`: list of `Claim`
- `challenges`: list of `Challenge`

**Output**:
- `verifications`: list of `VerificationResult` (updates claim status to VERIFIED, REJECTED, or CONTRADICTED)
